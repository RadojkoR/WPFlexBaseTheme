# WHS Frame — Modern, Flexible WordPress Theme

A powerful, modern WordPress theme designed for flexibility and ease of use. Built with Vanilla CSS and JavaScript, WHS Frame offers seamless integration with popular page builders while maintaining a lightweight footprint.

## Features

- **Top Bar** — Customizable top bar with email, phone, text, and social icons
- **Sticky Header** — Multiple sticky modes (always, scroll-up, or none) with smooth transitions
- **Transparent Header** — Beautiful transparent header that transitions to solid on scroll
- **Login/Signup Buttons** — Built-in authentication buttons with customizable styling
- **Language Switcher** — Native support for Polylang and WPML language switching
- **Elementor Pro Integration** — Full Theme Locations API support for custom headers and footers
- **Bricks Builder Integration** — Complete Bricks Builder theme locations support
- **Gutenberg Compatibility** — Full-width template and responsive design
- **React Admin Panel** — Modern settings interface with visual theme presets
- **Multiple Presets** — Light and Dark theme presets with one-click switching
- **Google Fonts** — Integrated Google Fonts loader with multiple font options
- **Font Awesome 6** — Complete Font Awesome Free icon library included
- **Mobile Responsive** — Fully responsive design with dedicated mobile menu
- **CSS Variables** — Advanced theming using CSS custom properties for easy customization

## Requirements

- **WordPress** 6.0 or higher
- **PHP** 7.4 or higher
- **Web Server** with standard WordPress hosting capabilities

## Installation

### Via WordPress Admin

1. Download the `whs-frame.zip` file
2. Go to **Appearance → Themes** in WordPress admin
3. Click **Add New** and select **Upload Theme**
4. Choose the `whs-frame.zip` file and click **Install Now**
5. After installation, click **Activate**

### Via FTP/File Manager

1. Extract `whs-frame.zip` on your computer
2. Upload the `whs-frame` folder to `/wp-content/themes/`
3. Go to **Appearance → Themes** in WordPress admin
4. Click **Activate** next to WHS Frame

## How to Use WHS Frame Settings Panel

After activating WHS Frame, access the theme settings via **WHS Frame Settings** in the WordPress admin menu (left sidebar).

### Settings Tabs

#### Themes Tab
Quick-switch between pre-configured theme presets:
- **Light** — Clean, bright theme with professional colors
- **Dark** — Dark mode with eye-friendly contrast
- **Ocean** — Teal-inspired theme with modern styling

Click any preset card to instantly apply all colors and settings.

#### General Tab
- **Primary Color** — Main accent color used throughout the theme
- **Secondary Color** — Supporting accent color for highlights
- **Background Color** — Page background color
- **Text Color** — Default text color
- **Container Width** — Content area maximum width (600–2560px)

#### Top Bar Tab
- **Enable Top Bar** — Show/hide the top bar above the header
- **Background Color** — Top bar background
- **Text Color** — Top bar text color
- **Link Color** — Top bar link and icon color
- **Hide on Mobile** — Collapse top bar on small screens
- **Dismissible** — Allow visitors to close the top bar
- **Column Content** — Configure left, center, and right columns (email, phone, text, social icons)

#### Navigation Tab
- **Header Background** — Header area background color
- **Header Text Color** — Header text and logo color
- **Navigation Link Color** — Menu link color
- **Sticky Header** — Choose header behavior (always sticky, sticky on scroll-up, or normal)
- **Transparent Header** — Enable transparent header mode
- **Login Button** — Enable/customize login button
- **Signup Button** — Enable/customize signup button
- **Button Style** — Choose between link or button styling
- **Button Colors** — Customize button background, text, border, and hover states

#### Mobile Tab
- **Mobile Menu Background** — Mobile menu panel background
- **Mobile Menu Text** — Mobile menu text color
- **Mobile Link Hover** — Mobile menu link hover color
- **Mobile Active State** — Active menu item background and text color
- **Close Button** — Customize the mobile menu close button appearance

#### Footer Tab
- **Background Color** — Footer background
- **Text Color** — Footer text color
- **Logo** — Separate logo for footer (optional)
- **Address** — Display address in footer
- **Email** — Contact email in footer
- **Phone** — Contact phone number in footer
- **Copyright Text** — Custom copyright notice

#### Social Tab
- **Social Icons** — Customize Font Awesome icon classes for each network
- **Social Links** — Enter URLs for Facebook, Instagram, Twitter, LinkedIn, YouTube, and TikTok
- **Display Colors** — Icon and link colors

## Customizer Settings
